

# Enhanced Travlr Getaways Application

This folder contains the enhanced version of the Travlr Getaways full-stack application developed for CS 499 Milestone Two: Software Design and Engineering.

## Improvements

- Authentication and role-based authorization
- Input validation and sanitization
- Centralized API error handling
- Secure CRUD operations
- Improved application maintainability
- Security-focused testing

## Purpose

These enhancements demonstrate my ability to identify weaknesses in an existing application and implement improvements that strengthen its security, reliability, and maintainability.

The original application is available in the ../original/ directory for comparison.
